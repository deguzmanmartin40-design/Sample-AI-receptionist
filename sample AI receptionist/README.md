# Sample AI Receptionist

Fictional Haven Retreats knowledge base with 12 passages for a small RAG demonstration.

Read Haven_Demo_RAG_README.md for setup and test questions. The SQL file creates a dedicated Supabase demo table and keyword retrieval function. JSON, CSV and a readable Markdown KB are also included.

This GitHub upload does not import data into Supabase. Database import and runtime verification are separate steps. No credentials or customer records are included.
